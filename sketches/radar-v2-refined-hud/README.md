## Variant: 精煉深色 HUD (爽感 V2)

### Design stance
保留聲納/火球語彙，但更克制：柔霧象限、淡軌跡、扁今日重點、表摺疊、時間軸播控。

### Key choices
- Main chart taller
- Soft radial zone fog (not hard color blocks)
- Playback as single timeline row
- Table collapsed by default

### Trade-offs
- Strong at: 好看且仍像「雷達」
- Weak at: 實作量略高於 ①

### Best for
爽感 V2、想延續現 V-穩但升級質感
